# 静音段处理

## 阈值规则

| 静音长度 | 处理 |
|---------|------|
| 同一句内部 ≥0.18秒 | **预选删除** - 句中卡顿 / 断续，不影响句间呼吸 |
| 句间 ≤0.8秒 | **保留** - 自然换气 / 句间节奏 |
| 句间 0.8-1.2秒 | **只记录，不预选** - 可能是思考停顿，人工判断 |
| ≥ 1.2秒 | **预选删除** - 明显卡顿或等待 |

## 输出格式

**整段标记，不拆分**

示例：3.2 秒静音 → 输出 1 条
```
| 64-66 | 12.86-15.80 | 静音3.2s | | 删 |
```

用户在审核网页中取消不想删的。不要默认删除 0.2-0.8 秒的正常句间停顿，否则会破坏口播听感；但如果该停顿落在火山转录同一个完整 utterance 内部，说明它更可能是句中卡顿，默认预选删除。

## 特殊情况

### 长静音
连续 5s+ 的静音整段标记，预选删除：
```
| 323-371 | 71.38-131.38 | 静音60s | | 删 |
```

### 开头静音
视频开头 ≥0.3 秒的静音必删：
```
| 0 | 0.00-1.00 | 静音1s | 开头静音 | 删 |
```

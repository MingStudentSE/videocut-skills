# 静音处理规则

静音预选由 `scripts/generate_auto_selected.js` 执行，Agent 只在复核或修改策略时读取本文件。

## 听感原则

- 同一句内部 `>=0.18s` 停顿默认删除。
- `<=0.8s` 的句间停顿默认保留。
- 句间 `0.8-1.2s` 只写入分析报告，不自动删除。
- `>=1.2s` 的连续静音块整段预选删除。
- 开头 `>=0.3s` 静音预选删除。

## 判断优先级

1. 优先使用火山转录的 `utterances` 判断句中/句间。
2. `generate_subtitles.js` 会把长静音拆成多个 1s gap。
3. 判断长静音时必须合并连续 gap run，不能逐个 1s 格子判断。

## 输出

脚本输出：

```text
auto_selected.json
静音分析.md
```

`静音分析.md` 会列出句中停顿、仅记录待人工判断、默认保留短停顿。

# 外挂字幕语义复核规则

## 复核目标

生成外挂字幕前，逐条检查转录文本，确保字幕既忠于视频口播，又符合个人热词和上下文语义。

## 个人热词

优先读取：

1. `.env` 中的 `VOLCENGINE_HOTWORDS_FILE`
2. `字幕/词典.txt`

热词用于两处：

- 转录前作为火山热词，提高 ASR 命中率。
- 转录后作为人工和大模型语义复核的专名清单。

## 必查问题

| 类型 | 检查方式 | 处理 |
|---|---|---|
| 产品名/人名/命令名 | 对照个人热词逐条查 | 只修正实际误识别 |
| 同音误识别 | 结合前后句语义判断 | 修正为符合上下文的热词或常用写法 |
| 英文大小写 | 对照热词写法 | 保持统一大小写，如 `Claude Code`、`API Key` |
| 漏字/错字 | 读整句是否通顺 | 只补视频中确实说出的字 |
| 语义不通 | 检查主谓宾和上下文 | 修正 ASR 错词，不改写表达风格 |
| 幻觉内容 | 原稿或上下文均不支持 | 删除该字幕条或标记给人工确认 |

## 大模型复核约束

- 只改不加：不能因为原稿或常识里有，就补视频中没说的话。
- 保持口语：不要把口播改成书面稿。
- 默认短字幕：必须使用字级 `utterances[].words[]` 时间戳重切。
- 时间戳来源：每条字幕 start 取该字幕第一个字/词的 `words[].start_time`，end 取最后一个字/词的 `words[].end_time`。
- 禁止比例拆分：不能按文本长度比例分配时间，否则段内字幕会漂移；也不能手工平移整条时间轴。
- 不确定就记录：把疑点写到 `语义复核.md`，不要静默猜测。

## 输出建议

复核后保存：

- `subtitles_with_time.json`：校对后的结构化字幕
- `语义复核.md`：记录主要修改和不确定项
- `3_输出/<视频同名>.srt`：默认外挂字幕
- `3_输出/<视频同名>.vtt`：网页播放器可用外挂字幕

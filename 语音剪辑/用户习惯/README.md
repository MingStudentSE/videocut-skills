## AI 审核顺序（按优先级）

1. **连续静音块 ≥1.2s** → 预选删（先合并连续 gap，再整段预选）
2. **同一句内部 ≥0.18s 停顿** → 预选删（使用火山 utterance 判断句中/句间）
3. **残句** → 删（话说一半 + 静音）
4. **重复句** → 删短的（开头≥5字相同）
5. **句内重复** → 删 A+中间（A+中间+A 模式）
6. **卡顿词** → 删前面（那个那个、就是就是）
7. **重说纠正** → 删前面（部分重复、否定纠正、词被打断）
8. **语气词** → 标记待人工确认（嗯啊呃）

## 核心原则

**删前保后**：后说的通常更完整，删除前面保留后面。
